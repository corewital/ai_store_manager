Proof of resolution — Allow pricing plan changes (1.2.3)

Resolved: merchants can upgrade/downgrade any plan (including Enterprise) without contacting support or reinstalling.

CorePilot AI uses Shopify App Pricing. In-app Settings → Billing opens Shopify’s hosted plan page (no Billing API charges; Managed Pricing).

Demo path for reviewers:

  1. Install CorePilot AI on a development store
  2. Open app → Settings → Billing
  3. Click Change plan on Shopify or Upgrade / Switch on any card (including Enterprise)
  4. Land on admin.shopify.com/store/…/charges/corepilot-ai/pricing_plans
  5. Select Free, Starter, Professional, Business, or Enterprise → approve
  6. Return to app; plan updates. Charge appears under Shopify Settings → Bills

Enterprise is a normal public plan ($99.99/mo, handle enterprise) — not “contact support.”
