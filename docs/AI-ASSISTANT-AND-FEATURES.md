## What CorePilot AI does

CorePilot AI is a Shopify embedded app that **scans your store**, finds catalog and SEO problems, and helps you **fix them with AI** — without reinstalling or leaving Shopify admin.

Typical workflow:

1. Run a scan (manual or automatic by plan)
2. See a **Health Score** and open issues (products, SEO, images, collections, etc.)
3. Preview AI suggestions → apply one-click or bulk fixes
4. (Business / Enterprise) Ask the **AI Assistant** for store-specific guidance

---

## AI Assistant (Business & Enterprise)

### What it is

An in-app chat (menu: **AI Assistant**) that answers questions using **your store’s live context**: health score, open issue counts, sample catalog problems, plan limits, and (when available) product/collection data from Shopify.

It is **not** a generic ChatGPT window. It is tuned for **store health, catalog quality, SEO, and growth next steps** for the shop where the app is installed.

### What you can ask

Examples:

- “What are my biggest store issues right now?”
- “Which products need better descriptions or SEO?”
- “How can I improve my health score this week?”
- “Summarize open collection / image problems”
- “What should I fix first before a sale?”

### What it does **not** do

- It does **not** auto-edit your theme liquid or checkout
- It does **not** replace the one-click fix modules (those live under Products / SEO / Images / Fixes)
- It does **not** invent store data — answers are grounded in scan results and catalog context when available

## Main features (all plans — scope varies by plan)

| Feature | Description |
|---------|-------------|
| **Health Score dashboard** | Weighted score from products, SEO, images, inventory, collections, navigation, theme |
| **Product scan & AI fix** | Missing titles/descriptions, weak copy — generate and apply |
| **SEO scan & AI fix** | Meta titles/descriptions for products and collections |
| **Image scan & optimize** | Missing media, oversized images (`sharp` compression), alt text suggestions |
| **Collection scan** | Missing descriptions, SEO meta, images |
| **Inventory / performance** | Flags and insights (Professional+) |
| **One-click / bulk Fixes** | Preview then save; queued fixes |
| **Reports** | In-app history; email digests on eligible plans |
| **AI Assistant** | Store-aware chat (Business / Enterprise) |
| **Theme app embed** | Optional Online Store embed (requires Online Store channel) |
